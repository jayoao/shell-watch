# 使用之開放資料來源

> LaborOD 組明文要求：「請於作品文件附上使用之開放資料來源名稱及網址。」
> 這一份就是要貼進報名／作品文件的那一段。**網址一律引用 data.gov.tw
> 的資料集頁面**，不要引用我們實際打的下載端點——評審看的是資料集本身。
>
> ⚠ 2026-10-30 更新為 20 筆（原本這份停在 7 筆、還寫著「尚未接入」，已過時）。
>   網站「關於資料」頁的清單與這份一致；改一邊要改另一邊。

## 篩選標準（每一筆都要四條都過）

1. **對得到一家事業單位**（有名稱或統一編號）—— 只有全國統計數字的表不用
2. **是主管機關的認定或公告**，不是公司自評
3. **講的是這家公司對勞工做了什麼**
4. **在畫面上有明確的角色**（下表的五種角色）

## 勞動部（含所屬機關）開放資料集　共 20 筆

| 44023 金安獎 | 主題最貼近（營造工程安全），但只有工程名稱、沒有公司名，對不到公司 |
| 152366 員工工作生活平衡措施、24036 托兒設施補助 | 只有全國申請家數與金額，沒有公司名單 |
